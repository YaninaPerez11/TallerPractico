# Taller Práctico de Git y GitHub

## Descripción

Este proyecto corresponde al taller práctico de HTML y CSS realizado en equipo. 
El objetivo es aplicar el uso de Git y GitHub para llevar un control de versiones 
y facilitar el trabajo colaborativo durante el desarrollo del proyecto.

Cada integrante del equipo desarrolló una página personal con una tarjeta (card) 
de presentación, utilizando HTML, CSS e imágenes.

## Control de versiones

Para el desarrollo colaborativo se utilizaron diferentes comandos de Git, entre ellos:

git init
git clone
git add
git commit
git branch
git checkout
git push
git merge
git diff

El uso de ramas permitió que cada integrante pudiera trabajar en sus cambios de manera independiente y posteriormente integrarlos al proyecto principal.
